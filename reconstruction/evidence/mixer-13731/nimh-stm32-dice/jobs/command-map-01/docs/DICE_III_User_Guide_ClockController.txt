18 Clock Controller 
 
18.1 Overview 
The Clock Controller controls the routing of audio sample clocks through the system, it 
selects sources for the JET PLL and has features to count sample clocks. 
 
18.2 Module Configuration 
The Clock Controller is addressed through one base address, CYGHWR_HAL_DICE3_CC. 
 
Table 18.1  Clock Controller base address 
Base address GPIO module number 
0xC4000100 Clock Controller

 Clock Domain Register – DICE_CLK_DOMAIN 18.2.1
Address offset: 0x0004     DICE_CLK_DOMAIN 
This register is used to set the rate mode and frame clock source for the system clock.  
 
31:6 5:4 3:2 1:0
Reserved
SYS_MODE
Reserved
FBSCR
 
Table 18.3  Clock Domain Register bit assignments 
Name Bit Reset Dir Description 
Reserved 31:6 0 N/A Reserved 
SYS_MODE 5:4 0 RW 
0 = low 
1 = mid 
2 = high 
Reserved 3:2 0 N/A Reserved 
FBSCR 1:0 0 RW 
Frame clock source. 
0 = Standard from Jet PLL 
1 = From WCLK0 input (if JET PLL is not used 
and chip is slaved to another chip) 
2 = From WCLK1 input (if JET PLL is not used 
and chip is slaved to another chip) 
3 = Free running (no 1fs reference) 
 
FBSCR: In all normal JET PLL cases this will be 0. In the case where the DICE III sync 
source is from an external source such as another DICE chip the FB signal can come 
from one of the WCLK inputs. In that case the system should be programmed to take 
F1024BR or F2048BR from the VCO in pin as well.

Table 18.4  Clock External Clock Register bit assignments 
Name Bit Reset Dir Description 
Reserved 31:6 0 N/A Reserved 
WCK1 5:3 0 RW 
Select source for word clock outputs 
0 = Off 
1 = fbr (base rate) 
2 = f2br (base rate X 2) 
3 = f4br (base rate X 4) 
4 = 1fs  (actual fs based on rate mode) 
5 = ref  (the reference event selected for the JET 
PLL) 
WCK0 2:0 0 RW 
Select source for word clock outputs 
0 = Off 
1 = fbr (base rate) 
2 = f2br (base rate X 2) 
3 = f4br (base rate X 4) 
4 = 1fs  (actual fs based on rate mode) 
5 = ref  (the reference event selected for the JET
