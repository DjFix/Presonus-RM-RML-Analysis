# Frontier small01 worker 01

Five exact RM 13731 symbols have partial portable implementations. Ordinary
return declarations, complete class definitions, original ownership and layout,
ARM ABI, full native provider behavior and hardware remain unresolved. This is
a compiled-pending delivery, not readiness admission.

`oracle.py` verifies the full ELF SHA-256 and each actual section/file range,
then executes the original instructions with Unicorn. BLs are observed app
boundaries; the filename callee writes an explicit sentinel, the rebuild callee
clears its dirty byte, and volatile argument registers are deliberately clobbered.
All writes and calls are retained. No Core body is decompiled or executed.
D1 ranges retain their vptr stores and real base-call target identities. They do
not establish D0 or native base cleanup behavior.

`replay.py` compares normalized caller traces from the compiled source to those
independent native traces. The driver wrappers call the real current app
providers, linked with pinned CCL 5.0.0. It asserts filename results against a
separate real provider call, manager filesystem rebuild notifications and dirty
state, FX name/type parameter results, base stream destruction, and control
observer/timer cleanup. The supplied application service doubles are explicit
fixture boundaries; they are never production Core implementations.

Domains: filename slots 0,1,2,15 of a 16-slot cache; UINT_MAX retained native-only.
Two D1 source states each: null/live stream and empty/populated control cleanup.
Borrowed nonnull arrays of lengths 0..4, including a repeated first object.
Collections and counts are stable during callbacks. Filename cache is clean and
seeded; manager caches start clean and are forced dirty before every rebuild.
FX slot equals loaded slot at index 2, type index zero, both reverb/delay classes.
Empty/missing-cache and invalid/nonfinite FX parameter states are excluded.

Run from repository root with the project Python:

```
uc-library/.venv/bin/python uc-library/candidates/frontier01_w01/checks.py format
uc-library/.venv/bin/python uc-library/candidates/frontier01_w01/checks.py compile
uc-library/.venv/bin/python uc-library/candidates/frontier01_w01/checks.py symbols
uc-library/.venv/bin/python uc-library/candidates/frontier01_w01/checks.py replay
```

Root owns production RM partition, global CMake, Linux full integration and
SQLite readiness fragments/admission. The supplied CMake target links the
production archive and does not duplicate the production CPP. The local compile
check recompiles all seven relevant existing app provider CPPs so changes in the
three owned public headers are actually compiled, then links the remaining
support from the existing RM archive and actual upstream Core libraries.
