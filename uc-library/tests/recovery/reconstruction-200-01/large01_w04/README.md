# Bounded original ARM versus source-port replay

148 leaf executions use exact SHA-bound original surface 13840 app instructions in Unicorn 2.1.4. All original target ranges and section/file offsets are independently checked with pyelftools. No Core firmware executes; the portable replay uses real pinned Core vectors and component/parameter implementations. Every unexercised dependency method in test-only fixtures aborts.

Container inputs cover valid nonnegative counts through and above the native fixed capacities (ten page observers, five assignment handlers), null and duplicate borrowed pointer identities. Negative corrupt native counts, allocation failures, full lifecycle and event delivery are excluded. Native object/array writes and changed bytes are captured; portable replay compares complete relevant count/pointer arrays and setter pointer identity. Getter outputs cover null/present clients/pages, flag low-bit behavior and signed offset extrema. String behavior does not establish original return declarations or const qualification. Mapping bool scope is canonical bytes 0/1.

New storage is intentional portable state, with no ARM layout claim. The existing opaque PageComponent pointer is retained. A single bindGeqPage update associates that exact identity with an explicit borrowed GeqPageComponent scroll view, with no inheritance/layout claim. Legacy mutable page access invalidates that association. Null pages return zero; a nonnull unbound page raises an explicit unsupported-binding exception instead of silently reading unrelated state. Portable binding regressions cover identity preservation, rebinding, stale-view rejection and null reset. DAW activation flags live in the same DAWMixerState used by existing methods. The mapping lock bit and preset controller use the same portable component state. No production no-op handlers were introduced.

Root must add the single production CPP to the CS18 object partition, add the explicit public header, rebuild consumers of modified headers, add this test subdirectory, and run the full Linux/role/admission gates. Local acceptance is not readiness.
