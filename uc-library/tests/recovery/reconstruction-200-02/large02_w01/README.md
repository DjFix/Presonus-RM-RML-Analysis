# SLMixerHandler bounded portable reconstruction

The maintained source proposal recovers the fourteen originals named in the
handoff index. Six originals remain explicitly blocked: the three destructor
variants and the GEQ-change, EQ-change and setController methods whose actual
large application helpers have no recovered implementation. Their original
ranges are retained in BLOCKERS.json; no default destructor earns target credit.

`oracle.py` executes exact SHA-256-bound original ARM app instructions in Unicorn.
Core firmware bodies are excluded. Hooks represent CCL parameters, lists, strings,
containers, mapping controller dispatch, MappingTable calls and timer boundary
queries. The portable driver calls actual pinned CCL 5.0.0 code, real existing
MappingTable, Assignment/MixerAssignment and DelayTimer implementations compiled
against the proposal header. Test subclasses observe the still-unreconstructed
updateConnections boundary and abort on unexpected unsupported methods.

`SLMappingState` is an explicit independent source-port composition. Its borrowed
CCL trees/vectors resolve the recorded original mixer virtual calls and flags;
it is not an original Mixer class/layout or a second original interface. The
existing SLMixerEncoderAccess and new SLMappingAccess bind that composition. It
must outlive the handler. EQ mode comes from a real CCL parameter list at tag1000.
The source port remains abstract where required original behavior is unresolved.

Each fixture preserves native call traces and semantic outputs. The radio
controller hook is non-mutating; control-color tests call the actual MappingTable
with an empty item table, transparently observing requested colors. No hardware
or panel callback is executed. Timer tests use stopped, frozen elapsed values
with the real portable DelayTimer provider; clock-running timer behavior is not
claimed. Float-to-int queries cover finite int-representable values. Name/string
and bool queries cover the recorded fixture domains, including sampled IEEE
values for bool queries. Unencoded original returns remain declaration-pending;
no ARM32 ABI/layout, complete device behavior or hardware validation is claimed.

Local validation uses `uc-library/.venv/bin/python
uc-library/candidates/large02_w01/checks.py replay`. It creates fresh assigned
scratch and copies mutable canonical Core archives with exact provenance before
linking. Source/header/test/fixture inputs remain unchanged during checks.

Canonical integration adds the production CPP once to the CS18 OBJECT partition,
recompiles all header dependents and existing providers, and registers this test
with explicit `--executable` and `--fixtures` arguments. Root retains full Linux,
installed-role, compile-once, active-source, guarded SQLite and tracker gates.
No ready/pending fragment or readiness admission is delivered by this worker.
