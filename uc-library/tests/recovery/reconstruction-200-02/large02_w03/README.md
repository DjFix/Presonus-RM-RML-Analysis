Controller/EQ portable source-port replay

The executable consumes a method number, input count and unsigned 32-bit words
per line. Each result contains an output count and unsigned words. The replay
script binds a supplied built executable to explicit sealed fixtures; CTest must
supply --executable and --fixtures exactly as in CMakeLists.txt.

Oracle fixtures execute original ARM application ranges. Soft-float/libm calls
are explicit arithmetic adapters. Core instructions are never executed. Real
pinned CCL headers/library, original reconstructed Controller/descriptor providers,
and Biquad provider CPP are compiled against the proposal overlay. Target
ownership/lifetime and dirty flags are tested with outliving observer state.

Ordinary original return declarations remain pending where not independently
proved. Portable return choices, storage, host vtables and property payload shapes
do not establish original class layout, ARM ABI or hardware interoperability.
EQ doUpdates currently validates actual calculator mode6 with finite sample rate
48000; other coefficient modes remain covered by their separate provider proof,
not by this replay. Inactive native band slots, oversized physical indices and unsafe float-to-int inputs are excluded. Controller base doUpdates remains pure and unresolved; supported callers use explicit test or actual EQ overrides.
