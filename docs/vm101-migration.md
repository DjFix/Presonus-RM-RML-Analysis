## Старые чаты

Все 53 исходных JSONL скопированы без изменения исходных байтов в `/home/rs/.codex/`. Из них 11 основных чатов зарегистрированы на VM через нативный `thread/resume`, без `turn/start` и без запуска исследований. Все ID ходов и элементов истории каждого чата сверены с исходными JSONL, включая родительские префиксы двух ответвлённых чатов.

Отчёты: `temp/vm-migration-20261028/chat-session-copy-receipt.json`, `chat-import-verification.json`, `opencs18-rollout-expectations.json`, `chat-names.json`. В первом отчёте импорта поле title взято из исходного запроса; отображаемые имена затем исправлены из поля name и подтверждены через desktop API.

Локальные оригиналы сохранены и доступны. Пробное архивирование локальных экземпляров отменено, поскольку оно не устранило ограничение desktop.

Текущая сборка desktop явно запрещает cross-host Hand off для `historyMode=paginated`. Это отдельное ограничение после исправления Git. На VM установлен Git 2.56.0: точная команда Codex с `safe.bareRepository=explicit` из `.git` теперь читает GitHub origin успешно.

Прямой импорт с прежними ID сохранял ошибочную локальную привязку desktop. Рабочее решение: создать нативные продолжения с полной унаследованной историей, затем по одному открыть их через `codex://threads/НОВЫЙ_ID?hostId=remote-ssh-discovered%3Avm101` в ChatGPT.app. Все 11 продолжений зарегистрированы в удалённом проекте `ai`; хост и canonical cwd подтверждены API. Пользователь подтвердил открытие без ошибок. Новых исследовательских ходов на этапе регистрации не запускалось.

Соответствие исходных и новых ID и отчёты сверки: `temp/vm-migration-20261028/remote-continuations.json`; кликабельная таблица — `docs/vm101-chats.md`. Исходные Mac-чаты и неизменённые VM-rollout сохраняются как история и резерв; они не являются рабочими продолжениями.

## Фоновый сервер и возобновление исследования

Установлен полный официальный CLI 0.165.0 в профиле rs, включая code-mode-host, rg и bwrap. Прежняя установка `/opt/codex/0.165.0/codex` сохранена.

После проверки отсутствия выполняющихся задач одиночный сервер заменён штатным управляемым демоном. Подтверждены `backend: pid`, managed version 0.165.0 и фактический executable в `/home/rs/.codex/packages/app-server-daemon/releases/`. PID 2497919 имеет PPID 1, собственные SID/PGID и не имеет TTY. Действующее свойство logind `KillUserProcesses=false`. К управляющему сокету подключается desktop с Mac; после переключения на нём восстановлены все 11 продолжений.

Отчёт переключения: `temp/vm-migration-20261028/daemon-cutover.json`. Полный CLI находится в `/home/rs/.local/bin/codex`; фоновым процессом управляет `codex app-server daemon`. Backend PID отделён от SSH-сеанса; установка не создаёт systemd unit и не включает автоматический запуск после перезагрузки VM.

Прежняя пауза Extract UC сохранялась во время миграции. Затем пользователь прямо разрешил после завершения переноса запустить удалённый Extract UC с субагентами. Перед запуском обновляется AGENTS.md с новым рабочим расположением и этим разрешением. Результат проверки продолжения работы при отключении управляющего соединения сохраняется отдельным отчётом.
