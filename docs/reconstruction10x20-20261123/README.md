# Воспроизведение отчёта контрольного цикла 10×20

Комплект читает сохранённые исходные квитанции, не запускает сборку, граф или операции SQLite. Python из окружения проекта и уже версионируемый агрегатор нужны на VM101. Пути к текущим квитанциям проекта задаются в cycle-inputs.json. Скрипты допустимо запускать из любого каталога с явным абсолютным путём к корню checkout. Для воспроизведения исторического снимка нужен соответствующий архив квитанций.

## Снимок при незавершённом цикле

```bash
bash "$report_tools/run_cycle_report.sh" \
  "$repository" "$report_tools/cycle-inputs.json" \
  --as-of "$observed_utc" --out "$snapshot_json"
```

## Итоговый отчёт

```bash
bash "$report_tools/run_cycle_final.sh" \
  "$repository" "$report_tools/cycle-inputs.json" \
  "$closing_milestones_json" "$verified_graph_aggregate_json" \
  "$observed_utc" "$output_prefix"
```

Манифест можно собрать из исходных отдельных квитанций командой assemble_closing_milestones.py. Она принимает пути к отдельным квитанциям, каждой провалившейся попытке графа, проверенному графу и его агрегату. Для фаз графа account_source_publication.py сверяет хешируемый source journal, таймаут native-транзакции и журнал продолжения. Источник считается один раз по идентификатору подтверждённого события.

Манифест закрывающих этапов должен содержать ровно четыре действительные записи admission, closing_graph, pinned_codec и historical_reseal. Каждая содержит observed UTC, путь и SHA-256 каждой квитанции. Выходные файлы сохраняют измерения, сравнение, независимую проверку первичных слотов и Markdown. Существующие результаты сохраняются. Ранее принятые отдельные задания и ABI/role варианты учтены отдельно от первичных заданий.

Команду снятия provider counters запускают отдельно через uc-library/tools/recovery/collect_cycle_cost.py cutoff после фактического конца. Для неё нужна исходная квитанция baseline. Commit отчёта, если требуется его точное время, учитывается отдельно от операционной отсечки.

Для сохранённого итогового отчёта используйте наблюдение 2026-11-24T01:12:51Z и агрегат temp/recovery-work/control10x20-after-4fed70d11/graph/AGGREGATE-final.json. Манифест closing-milestones.json лежит рядом со скриптами. Смена имени выходного префикса меняет путь квитанции в comparison.json. Её хеш и рассчитанные значения остаются прежними.
